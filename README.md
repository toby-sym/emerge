# Emerge

> **Development Paused — Framework Limitations**

Emerge is an experimental artificial-life simulation written in C#.

Development has been **paused indefinitely**. The project reached a point where the performance characteristics of **WinUI 3** became a significant limitation for the rendering workload, making it unsuitable as the long-term desktop UI framework for the project.

Rather than continuing to build around a framework that was becoming a bottleneck, development has been stopped while alternative approaches are considered.

### Status

* **Development:** Paused
* **Reason:** WinUI 3 rendering / performance limitations
* **Maintenance:** None planned
* **Future:** May be restarted using a different rendering / UI technology

The existing code is preserved as a record of the project's development and experimentation.
